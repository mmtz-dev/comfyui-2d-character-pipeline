# Which pixel-art-style LoRAs exist for Z-Image-Turbo and Qwen-Image / Qwen-Image-Edit 2509 (usable for 64×64-scale game sprites), and are any suitable for Wan 2.2?

## Short answer

Several small, ungated, Apache-2.0-licensed pixel-art LoRAs exist for Z-Image-Turbo (best: `tarn59/pixel_art_style_lora_z_image_turbo`) and for Qwen-Image (best: `artificialguybr`'s PixelArt.Redmond Qwen version and `prithivMLmods/Qwen-Image-2512-Pixel-Art-LoRA`); none of these are trained specifically for the Qwen-Image-Edit-2509 checkpoint, though the base Qwen-Image LoRAs are commonly reported to work on Edit variants since they share the same DiT backbone (unconfirmed by a primary source). For Wan 2.2, two relevant LoRAs exist for sprite/pixel-art animation (`styly-agents/Wan2-2-pixel-animate` for I2V-A14B, and a Civitai "wan2.2 pixel-style attack sprite animation" LoRA), both Apache-2.0. The repo's own `gpu/models.lock` already tracks one of the Qwen-Image pixel-art LoRAs (`prithivMLmods/Qwen-Image-2512-Pixel-Art-LoRA`) and that row is currently **disabled** because the file the Hugging Face CDN serves does not match the sha256 the HF API advertises — this looks like an upstream LFS-pointer/metadata bug at prithivMLmods' repo, not a corrupt local download.

[huggingface.co/reverentelusarca/elusarca-pixel-art-style-lora-zimage-turbo](https://huggingface.co/reverentelusarca/elusarca-pixel-art-style-lora-zimage-turbo)

[huggingface.co/SkyAsl/Pixel-artist-Z](https://huggingface.co/SkyAsl/Pixel-artist-Z)
- All three ship as plain `.safetensors` single-file LoRAs with standard PEFT/kohya-style tensor naming for a DiT model; the tarn59 and Civitai-mirrored versions explicitly show ComfyUI-generated sample images, implying they load in ComfyUI's standard `LoraLoader`/`LoraLoaderModelOnly` node once Z-Image-Turbo is set up (no custom loader mentioned). [huggingface.co/tarn59/pixel_art_style_lora_z_image_turbo](https://huggingface.co/tarn59/pixel_art_style_lora_z_image_turbo)

## Findings — Qwen-Image / Qwen-Image-Edit 2509 pixel-art LoRAs

- `prithivMLmods/Qwen-Image-2512-Pixel-Art-LoRA` — see lockfile section above; base `Qwen/Qwen-Image-2512`, Apache-2.0, 1,179,885,016 bytes (~1.1 GB, rank 64), trigger `"Pixel Art"`, recommended 45–50 steps (or 4–8 with a Lightning/Turbo adapter), 905 monthly downloads, used in 5 community Spaces. Currently fails the project's own hash pin (see above). [huggingface.co/prithivMLmods/Qwen-Image-2512-Pixel-Art-LoRA](https://huggingface.co/prithivMLmods/Qwen-Image-2512-Pixel-Art-LoRA)
- `artificialguybr/PIXELART-REDMOND-QWENIMAGE` (HF mirror): base `Qwen/Qwen-Image-2512`, Apache-2.0, file `[Qwen.Image]PixelArt_Redmond.safetensors` = 590,058,920 bytes (~563 MB), trigger `"Pixel Art, PixArFK"`, last modified 2026-07-20, 82 monthly downloads on HF, author explicitly recommends ComfyUI for best results. [huggingface.co/artificialguybr/PIXELART-REDMOND-QWENIMAGE](https://huggingface.co/artificialguybr/PIXELART-REDMOND-QWENIMAGE)
- Same LoRA on Civitai, "PixelArtRedmond – Pixel Art Loras", Qwen-Image version specifically (model id 144684, version id 2696876): file 576,229 KB (~563 MB, matches HF size), trigger words `["Pixel Art", "PixArFK"]`, published 2026-02-17, 1,326 downloads on that version (10,812 across all base-model versions of this LoRA family, which also includes SDXL/Z-Image-Turbo/Flux.2-Klein-9B variants), 55 thumbs-up on the Qwen version, 821 thumbs-up overall. Civitai's own permissions flags: `allowCommercialUse: [Image, RentCivit, Rent]`, `allowNoCredit: true`, `allowDerivatives: true`, `allowDifferentLicense: false` — broader commercial terms than a bare "Apache-2.0" tag but confirmed non-gated and reusable. [civitai.com/api/v1/models/144684](https://civitai.com/api/v1/models/144684)
- No primary-source pixel-art LoRA was found trained specifically against the `Qwen-Image-Edit-2509` checkpoint (searches surfaced only generic style/in-scene editing LoRAs for that checkpoint, e.g. `flymy-ai/qwen-image-edit-2509-inscene-lora`, none pixel-art). Community Spaces (`prithivMLmods/Qwen-Image-Edit-2509-LoRAs-Fast`) let users plug in base Qwen-Image LoRAs for edit-style workflows, which suggests cross-compatibility in practice, but this is not documented on any model card as an officially supported combination — treat as unverified. [huggingface.co/spaces/prithivMLmods/Qwen-Image-Edit-2509-LoRAs-Fast](https://huggingface.co/spaces/prithivMLmods/Qwen-Image-Edit-2509-LoRAs-Fast)
- All Qwen-Image LoRAs above are single-file `.safetensors`, kohya/PEFT-style naming for a DiT — the same format ComfyUI's official Qwen-Image LoRA workflows (`Comfy-Org/Qwen-Image_ComfyUI`, already in this repo's lockfile) expect, so they are expected to load via the standard `LoraLoader` node; no custom loader is mentioned on any of the three cards.

## Findings — Wan 2.2 (i2v / Fun-Control) pixel-art / sprite-animation LoRAs

- `styly-agents/Wan2-2-pixel-animate`: base `Wan2.2-I2V-A14B`, license Apache-2.0 (card references the Wan 2.2 base-model license for downstream use), file ≈2.3 GB, no single fixed trigger word documented, recommended LoRA strength 1.0, trained on 226 pixel-art sprite-animation clips at 600×370, ships a ComfyUI workflow (`wan2-2-video.json`) and explicit instructions to load via `LoraLoaderModelOnly` with a 4-step distillation LoRA, `ModelSamplingSD3` shift 5.0, CFG 1.1 — 1,062 monthly downloads. [huggingface.co/styly-agents/Wan2-2-pixel-animate](https://huggingface.co/styly-agents/Wan2-2-pixel-animate)
- Civitai "wan2.2 pixel-style attack sprite animation lora" v2.0: base Wan Video 2.2 I2V-A14B, Apache-2.0, 146.34 MB, no single documented trigger word, uploaded 2025-10-30, 996 downloads / 172 positive ratings, trained on ~30 melee-attack sprite clips at 512×512 (28 frames); card explicitly instructs inputs be low-res (~64×64) pixel-style characters upscaled to 512×512 before animating, and recommends pairing with a 4-step LightX2V accelerator LoRA. This is the closest primary-source match to the 64×64-sprite use case. [civitai.com/models/2085866](https://civitai.com/models/2085866/wan22-pixel-style-attack-sprite-animation-lora)
- Civitai "Pixel Art Animation (Birdman Style) – Wan 2.1 I2V LoRa" v1.5: base is **Wan 2.1** 14B I2V 480p (not 2.2), Apache-2.0, 342.61 MB, trigger `p1x3lStyl3`, recommended strength 1, uploaded 2025-04-05, 6,874 downloads, 1,000 "Overwhelmingly Positive" ratings — strong community track record but not compatible with Wan 2.2 checkpoints without cross-version testing. [civitai.com/models/1431085](https://civitai.com/models/1431085/pixel-art-animation-birdman-style-i-wan-21-i2v-lora)
- No Fun-Control-specific (i.e. targeting `alibaba-pai/Z-Image-Turbo-Fun-Controlnet-Union` or a Wan Fun-Control checkpoint) pixel-art LoRA was found; the two Wan LoRAs above target the base I2V-A14B checkpoint already pinned in this repo's `gpu/models.lock`, not the Fun-Control variant.

## Ranked shortlist (top 5 overall)

1. **`tarn59/pixel_art_style_lora_z_image_turbo`** (Z-Image-Turbo, Apache-2.0, 162 MB) — highest download count and community traction of any candidate (~12k/month), small file, clean single trigger phrase. [link](https://huggingface.co/tarn59/pixel_art_style_lora_z_image_turbo)
2. **Civitai "wan2.2 pixel-style attack sprite animation lora"** (Wan 2.2 I2V-A14B, Apache-2.0, 146 MB) — the only Wan-2.2 LoRA whose own documentation explicitly targets 64×64-scale pixel sprites upscaled to 512×512, directly matching this project's animation pipeline. [link](https://civitai.com/models/2085866/wan22-pixel-style-attack-sprite-animation-lora)
3. **`artificialguybr` PixelArt.Redmond, Qwen-Image version** (Qwen-Image-2512, Apache-2.0/Civitai-open, ~563 MB) — largest, most mature LoRA family (10.8k total downloads, 821 thumbs-up), author explicitly recommends ComfyUI, available redundantly on both HF and Civitai. [HF link](https://huggingface.co/artificialguybr/PIXELART-REDMOND-QWENIMAGE) / [Civitai link](https://civitai.com/models/144684/pixelartredmond-pixel-art-loras)
4. **`styly-agents/Wan2-2-pixel-animate`** (Wan 2.2 I2V-A14B, Apache-2.0, ~2.3 GB) — largest, most purpose-built pixel-sprite animation dataset (226 clips) with a ready-made ComfyUI workflow shipped in the repo. [link](https://huggingface.co/styly-agents/Wan2-2-pixel-animate)
5. **`prithivMLmods/Qwen-Image-2512-Pixel-Art-LoRA`** (Qwen-Image-2512, Apache-2.0, ~1.1 GB) — already the project's chosen candidate in `gpu/models.lock`; ranked lower only because the upstream file currently fails hash verification and needs an owner decision before use. [link](https://huggingface.co/prithivMLmods/Qwen-Image-2512-Pixel-Art-LoRA)
