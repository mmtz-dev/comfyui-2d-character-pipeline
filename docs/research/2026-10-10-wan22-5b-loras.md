# Is there a public LoRA for Wan 2.2 TI2V-5B / Fun-Control 5B that pushes toward pixel art, sprite animation, or flat style?

## Short answer
No pixel-art or sprite-animation LoRA for the 5B model turned up on Civitai or Hugging Face (as of 2026-10-10). The only 5B style LoRAs that fit are motimalu's "Flat Color - Style" (v2.0 [wan-ti2v-5b]) and the Hollow Knight 5B LoRA (2D game look). Every pixel/sprite LoRA found targets Wan 2.1 or Wan 2.2 14B and will not load on 5B.

## Findings
Method: Civitai public API filtered to base model "Wan Video 2.2 TI2V-5B" (about 35 LoRAs listed, searched by pixel, sprite, flat, retro, 2d, cartoon, cel, anime, game) plus Hugging Face model search. A text-only, non-exhaustive search; a small unlisted LoRA could be missed.

### 5B candidates (compatible base)
- **Flat Color - Style, version "v2.0 [wan-ti2v-5b]"** (version id 2076237), by motimalu.
  - URL: https://civitai.com/models/1132089?modelVersionId=2076237
  - File: `wan_flat_color_2.2.5b_v2.safetensors`, 153.8 MB.
  - Base: Wan2.2-TI2V-5B, trained with diffusion-pipe, rank 32, image-only dataset, flagged "experimental" and "less effect at longer framerates".
  - Trigger: none listed for the 5B version. The model-level recommended tags are `flat color, no lineart, blending, negative space, {{color}} background`.
  - Strength: not stated by the author.
  - SFW: model flagged non-NSFW.
  - License: Civitai terms, not CC/Apache. Flags: no credit required, derivatives allowed, commercial use for Image, Rent and RentCivit only (no Sell). Treat as not permissive.
  - ComfyUI: author states the preview videos were made with the stock ComfyUI Wan 2.2 text-to-video example, loading the LoRA with `LoraLoaderModelOnly`. That was the base TI2V-5B, not Fun-Control; no Fun-Control test is documented.
  - Fit: flat colour without line art, not pixel art. Only a weak nudge for a pixel sprite.
- **Hollow knight [Wan 2.2], version "ti2v-5B"** (version id 2078128).
  - URL: https://civitai.com/models/1836374?modelVersionId=2078128
  - File: `hollow_knight_r032_5e-05_wan5B.safetensors`, 154 MB.
  - Trigger: `hollow_knight`. Strength: not stated in API data (details are in the author's article https://civitai.com/articles/18479/hollow-knight-wan-22-ti2v-5b, which I did not fetch).
  - SFW: non-NSFW flag. Licence: Civitai terms (Image, Rent, RentCivit, Sell, SellMerge allowed).
  - Fit: trained on Hollow Knight game footage at 1280x704, so it pushes a hand-drawn 2D game look and Hollow Knight characters. It is not pixel art, and it is third-party IP.
- **Retro 90's Anime / Golden Boy Style**, version "Wan 2.2 TI2V-5B" (id 2560443): https://civitai.com/models/1671285?modelVersionId=2560443. File `goldenboylora-22-5B-e145.safetensors`, 154 MB. Anime style, no trigger listed, Civitai terms. Not pixel or flat in the sense you need. The model title says "14B" but this version's base is 5B.
- Hugging Face: none relevant. 5B LoRA repos found are unrelated (oil painting, maze, DMD step-distill, adult or celebrity content, etc.). Example: https://huggingface.co/svjack/Landscape_to_Oil_Painting_wan_2_2_5B_TI2V_lora

### Compatibility facts
- Fun-Control 5B has the same transformer width and depth as TI2V-5B (dim 3072, 30 layers, 24 heads), only `in_dim` is 148 (vs 48) with an added reference conv. LoRA targets such as attention and FFN weights should therefore have matching shapes. A LoRA that trains `patch_embedding` would not match. This is my inference from the configs; I found no documented test of a 5B LoRA on Fun-Control. https://huggingface.co/alibaba-pai/Wan2.2-Fun-5B-Control/raw/main/config.json , https://huggingface.co/Wan-AI/Wan2.2-TI2V-5B/raw/main/config.json
- Wan 2.1 1.3B LoRAs do not load on 5B: 1.3B has dim 1536 / ffn 8960 / 12 heads, 5B has dim 3072 / ffn 14336 / 24 heads, so tensor shapes differ. https://huggingface.co/Wan-AI/Wan2.1-T2V-1.3B/raw/main/config.json
- Wan 2.1 14B (dim 5120, 40 layers, ffn 13824) and Wan 2.2 14B (same architecture family) LoRAs also mismatch 5B. https://huggingface.co/Wan-AI/Wan2.1-T2V-14B/raw/main/config.json
- Wan 2.2 5B base model license is Apache-2.0; Fun-Control 5B is Apache-2.0. https://huggingface.co/alibaba-pai/Wan2.2-Fun-5B-Control

### Best pixel/sprite options, all 14B or 1.3B (will NOT load on 5B)
- Pixel Art Animation (Birdman Style), Wan 2.1 14B I2V, trigger `p1x3lStyl3`, 343 MB; HF mirror licence listed openrail++. https://civitai.com/models/1431085 , https://huggingface.co/Muapi/pixel-art-animation-birdman-style-i-wan-2.1-i2v-lora
- wan2.2 lora, walk animation, side view sprite, pixel style: Wan 2.2 I2V-A14B, high-noise file 146 MB (low-noise pair is on HF `theamusing/wan2.2_pixel_walk_lora`), trigger `pix3lwalk`, weight 0.7-0.9, 24 frames at 16 fps. https://civitai.com/models/2172038
- wan2.2 pixel-style attack sprite animation lora: Wan 2.2 I2V-A14B, high-noise 146 MB, needs low-res pixel input; low-noise pair on HF `theamusing/wan2.2_pixel_attack_lora`. https://civitai.com/models/2085866
- Wan_Video_Attack_Sprite_Animation (Teluv): Wan 2.2 I2V-A14B, high-noise 146 MB. https://civitai.com/models/1924815
- Pokemon Sprite Animation Video LoRA: Wan 2.1 1.3B (84 MB) and 14B T2V (293 MB, trigger `pokemon`). https://civitai.com/models/1595383
- 2D Pixel Toolkit: Wan 2.1 14B T2V, 585 MB, triggers `SYK006`, `pixel art`. https://civitai.com/models/1656375
- All above are non-NSFW flagged and under Civitai-style or openrail++ terms, none CC/Apache. Sizes and triggers from the Civitai API.

### Practical consequence
For 5B the realistic options are: try Flat Color v2.0 [5B] at low strength (start around 0.5-0.8, my guess, unverified) alongside prompt wording and the pixel-grid post-processing already in the pipeline; or train your own 5B LoRA on your sprite sheets (the 5B trains on a 24 GB card per ai-toolkit docs, https://ai-toolkit-docs.runcomfy.com/models/wan22-5b ) which also avoids the licence limits; or switch to Wan 2.2 14B I2V with the walk/attack sprite LoRAs.
