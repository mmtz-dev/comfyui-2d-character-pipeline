How to judge this

  • Readability at 64px. Cover the animated preview. Can you tell what the pose is from a single frame, at 1× size, at arm's length? The art bible's whole premise is true 64px detail, not a shrunk illustration.
  • Anatomy under load. This is the reason the spike exists — both practitioners' 2D chains held up for walking and fell apart on attack, jump and roll. Count fused limbs, extra fingers-as-blobs, a sword that grows out of the wrong arm, a leg that changes length between frames.
  • Silhouette continuity. Flip between frames. Does the unit stay the same character, the same height, the same armour, or does it re-roll identity every frame?
  • Palette and alpha. Both arms go through the same anim post, so any difference here is a bug in the chain, not evidence about 2D vs 3D.
  • Nudge cost. Which set would take less time to fix by hand in Pixelorama? That is the number that actually decides a 100+ animation rollout.
Read this before scoring. The 3D column did not come from the owner's filmed performance. It came from a canned Mixamo clip re-projected through a rig. If it wins here, it wins at pose fidelity and loses at "my motion, my timing" until a video→3D-mocap step is built — and the obvious candidates (WHAM, TRAM, GVHMR, SMPLer-X) are all licence-blocked for a commercial game.
